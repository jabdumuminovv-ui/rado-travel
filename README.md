# TourHub Uzbekistan — Онлайн-поиск и бронирование туров (B2C + B2B)

Единая поисковая система туров по всем надежным туроператорам Узбекистана и Центральной Азии.

## Что реализовано:

1. **Режим B2C (для клиентов и туристов):**
   - Клиентский интерфейс без технических терминов.
   - Удобная форма бронирования: выбор отеля, ввод имени и телефона (`+998...`).
   - Заявки сохраняются на сервере (`bookings.json`) со статусом и уникальным номером бронирования (`#TR-XXXXXX`).
   - Кнопка быстрой связи в Telegram с предзаполненным сообщением по выбранному туру.
   - Расчет ориентировочной стоимости в узбекских сумах (UZS).

2. **Режим B2B (для турагентов и менеджеров):**
   - Переключатель в верхней панели переводит интерфейс в режим турагента.
   - Показывает точное название туроператора (Kompas Tour, EasyBooking, Selfie Travel, Kazunion и др.).
   - Предоставляет прямую кнопку перехода в корзину туроператора (`/bron?CATCLAIM=...`) под вашим логином.

3. **Исправленный маппинг направлений:**
   - **ОАЭ (Дубай, Шарджа):** точные ID для каждого туроператора (Kompas: 23, EasyBooking: 13, Selfie: 13, Kazunion: 11).
   - **Турция (Анталья):** Kompas: 17, EasyBooking: 9, Kazunion: 6.
   - **Египет (Шарм-эль-Шейх):** Kompas: 37, EasyBooking: 10, Selfie: 10.
   - **Мальдивы, Таиланд, Вьетнам, Катар, Маврикий, Сейшелы, Грузия**.

## Запуск

1. Запустите файл `run.bat` (или в терминале: `.venv\Scripts\uvicorn app.main:app --reload --port 8000`).
2. Откройте в браузере: `http://127.0.0.1:8000`
